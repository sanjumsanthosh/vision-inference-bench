What the numbers do and don't say

A quantization result is two claims: it got faster, and it still works. Only the first one is measured here.

The sample prediction changed class — 354 Arabian camel (FP32) → 723 pinwheel (INT8), with a maximum absolute logit difference of 21.43 and a mean of 3.32. One image proves nothing about accuracy either way, which is exactly why held‑out accuracy is reported as null rather than skipped.
  • The camel → pinwheel disagreement needs bisecting across PyTorch, exported FP32, prepared FP32 and INT8 before anyone says "accuracy‑preserving".
  • Labelled evaluation images must map Imagenette's 0–9 to ImageNet's 0–999; the guard rejects reused calibration paths but not a copied file.
  • One matching top‑1 prediction would still not establish accuracy.
  • Calibration and sample images aren't bundled, and the snapshot has no hashes — exact reproduction isn't possible from this repo alone.
  • CPU only: no GPU/DSP, Snapdragon, headset, power, or camera‑to‑result latency claims.
  • The latency table compares ONNX FP32 vs ONNX INT8 — not PyTorch vs ONNX.
